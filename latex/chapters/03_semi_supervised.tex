\chapter{Self-training for Semi-supervised Learning}\label{exp:07}

\runninghead{Experiment 7: Self-training for Semi-supervised Learning}

\quickfacts
  {Dataset}{Breast Cancer Wisconsin (569 $\times$ 30, binary); training set 398 samples with only 15\% labeled (61), 337 unlabeled}
  {Key parameters}{RBF-kernel SVC (C = 1, probability = True), confidence threshold $\tau$ = 0.80, max\_iter = 15}
  {Headline result}{Baseline 0.9298 $\rightarrow$ self-training 0.9415 (fully supervised ceiling 0.9766)}

\section{Objective}
Use a small labeled subset and a larger unlabeled subset, iteratively adding high-confidence
pseudo-labels, and compare against a supervised baseline and the fully supervised ceiling.

\section{Suggested Dataset}
Breast Cancer Wisconsin (569 $\times$ 30, binary). Stratified 70/30 split; only 15\% of the
training labels are kept, the rest are masked as unlabeled ($-1$).

\section{Required Libraries}
scikit-learn, numpy.

\section{Brief Theory}
Given a labeled set $L$ and an unlabeled pool $U$, self-training repeats:
\begin{enumerate}
  \item train the base classifier $f$ on $L$;
  \item compute class probabilities $f(x)$ for every $x \in U$;
  \item select the predictions whose maximum probability exceeds the threshold $\tau$ and add
        them to $L$ as \textbf{pseudo-labels};
  \item remove those samples from $U$;
  \item repeat until no new labels pass the threshold or the iteration limit is reached.
\end{enumerate}
The threshold controls the purity/quantity trade-off: a low $\tau$ admits wrong pseudo-labels
(confirmation bias), while a very high $\tau$ admits too few to help. The base estimator must
expose \texttt{predict\_proba}, which is why the SVC is calibrated
(\texttt{probability=True}).

\section{Procedure}
\begin{enumerate}
  \item Split the data stratified and scale the features (fit on training data only).
  \item Mask 85\% of the training labels to $-1$.
  \item Train a supervised baseline SVC on the labeled 61 samples.
  \item Wrap an RBF SVC in \texttt{SelfTrainingClassifier} with $\tau = 0.80$ and fit on the
        labeled plus unlabeled data; monitor the iterations.
  \item Train a fully supervised SVC on all 398 labels as the ceiling.
  \item Compare accuracy and F1 on the untouched test set.
\end{enumerate}

supervised model; the remaining gap is the cost of noisy pseudo-labels.

\section{Viva / Discussion Questions}
\begin{enumerate}
  \item \textbf{What is a pseudo-label?}\par\nobreak A predicted label for an unlabeled sample that the model
  accepts as a training target because its confidence exceeds the threshold.
  \item \textbf{What is confirmation bias in self-training?}\par\nobreak The model reinforces its own mistakes:
  wrong confident predictions enter the training set, make the model more confident about
  similar errors and can degrade performance. High thresholds and convergence monitoring
  mitigate this.
  \item \textbf{Why must the test labels remain hidden during training?}\par\nobreak Otherwise the evaluation is
  contaminated: test data would influence the model and the reported accuracy would no longer
  estimate generalization.
  \item \textbf{What does the confidence threshold control?}\par\nobreak The purity/quantity trade-off of
  pseudo-labels; 0.80 balanced the two here (convergence after four useful iterations).
  \item \textbf{Why does the SVC need \texttt{probability=True}?}\par\nobreak The wrapper requires
  \texttt{predict\_proba}; a plain SVC outputs only decision values, so Platt scaling is
  enabled.
\item \textbf{How can pseudo-labels be sanity-checked when no test labels are available?}\par\nobreak Hold out a small manually labelled set, inspect confidence distributions, and compare behaviour before and after adding pseudo-labels; agreement on held-out labels is evidence they are useful.
\end{enumerate}
