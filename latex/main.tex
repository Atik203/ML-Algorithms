\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}
This manual covers the complete Machine Learning Laboratory sequence: clustering
(K-means, modified K-means, hierarchical, fuzzy C-means), density-based learning
(DBSCAN, HDBSCAN), semi-supervised learning (self-training), ensemble learning
(random forest regression/classification, XGBoost, AdaBoost, CatBoost), neural
networks (MLP, RNN/LSTM), self-organizing maps, hidden Markov models, support
vector machines, large language models and generalized regression neural networks.

Every experiment follows the same eight-part report format: Objective; Suggested
Dataset; Required Libraries; Brief Theory; Procedure; Reference Implementation;
Evaluation / Expected Output; and Viva / Discussion Questions, extended with the
complete executed code listing and the observed results. All experiments were run
on real, public datasets with fixed random seeds; the full programs are included
so that each experiment can be reproduced standalone.

\vspace{4mm}
\textbf{Environment.} Python 3.12, NumPy/Pandas, scikit-learn, XGBoost, CatBoost,
PyTorch (CUDA), Hugging Face \texttt{transformers}, MiniSom and hmmlearn.
Random seeds are fixed throughout (\texttt{random\_state=42}).
