\textbf{Conclusions.} (1) On small tabular classification, simple
boosting (AdaBoost) or bagging (RFC) match heavier models; the
differences are within noise. (2) On larger regression data, gradient
boosting clearly wins (R² ≈ 0.80 vs 0.74). (3) Clustering algorithms
agree on well-separated data; density methods are the only option for
arbitrary shapes and noise. (4) Fair comparison requires identical
splits, fixed seeds, untouched test sets, and reporting at least two
metrics per task.

\textbf{Common mistakes avoided.} Scaling fitted only on training data;
no repeated test-set peeking; same partitions for all models; F1/AUC
reported alongside accuracy; cluster labels never treated as ground
truth; one hyperparameter changed at a time; prompts and model versions
recorded; no private data sent to external models.

  Python 3.12 (\passthrough{\lstinline!.venv!}) and all package versions

  Random seeds fixed everywhere
  (\passthrough{\lstinline!random\_state=42!},
  \passthrough{\lstinline!random\_seed=42!},

  Preprocessing recorded: scaling fitted on training data only;
  haversine radians for geospatial data; MinMax for SOM/RNN.
\item
  Train/validation/test protocols recorded (stratified, chronological,
  early-stopping split, 5-fold CV).
\item
  Hyperparameters documented per experiment in the notebooks and this
  report.
\item
  Metrics defined before final testing; no test-set model selection.
\item
  Figures and tables saved inside the executed notebooks and the printed
  PDFs.
\item
  Code runs from the committed \passthrough{\lstinline!.venv!} with the
  listed dependencies; GPU optional (CPU fallback automatic).
